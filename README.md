# 從學習證據到教學改進——AI 協作促進學習評量與教學實踐研究工作坊

給大學教師的 2 小時動手工作坊教材：帶一門課、一個評量任務來，跟 AI 助手一起把課程資料夾變成有紀錄的證據、把評分規準（Rubric）從第 1 版改到第 2 版、抽查 AI 對學習證據的分析、填一頁可以直接長成計畫書的設計。指令交給 AI 代打，老師只看它的計畫、看它改完的前後對照、然後點頭。

**線上版**：https://cwstedctw.github.io/learning-evidence-workshop/

**場次**：2026-10-16（五）15:00–17:00，國立東華大學環境學院 3F CIRES 會議室。東華「動手做科學融入教學課程 11」教師社群 × 宜蘭大學東區 ISW 教師社群合辦。全場只用合成示範資料，老師不需要帶任何真實的學生資料。

## 兩句話說明

四塊都是老師自己動手：有紀錄的課程資料夾 → Rubric 第 1 版改到第 2 版 → AI 分析＋人工抽查 → 一頁「評量—回饋—教學調整—研究」設計。每一步都由 AI 助手在你電腦上代打（ChatGPT 桌面版的 Codex；免費備援 Antigravity）；行前裝不起來的人提早 20 分鐘到現場一起裝。

全場只記一句話：**挑一句不同意的、改掉、寫下為什麼。** AI 只整理既有的分數與文字，不替老師打分數、不替老師下結論。

## 跑守門腳本

需要 Node.js（跟 `.github/workflows/validate.yml` 用同一版），不裝任何套件：

```
node validate-workshop.mjs
```

它會檢查資料源欄位齊不齊、議程合不合計 120 分鐘、頁面有沒有占位符或陸式用語、那一句話有沒有出現在該出現的頁、工作台按鈕名稱跟講義對不對得上、示範資料筆數與欄位、投影片頁數與圖。任何一條不過就 exit 1；缺檔會印出缺哪個、誰負責，不會崩潰。

## 資料怎麼放、怎麼給 AI

- 教材本身只放合成資料；`.gitignore` 已排除 `my-course/`、`real-data/`，老師自己課程的資料請放私人 repo。
- 丟給雲端 AI 之前，先把姓名、學號、能認出人的細節拿掉。
- AI 的分析要回頭抽查——抽查本身就是研究方法的一部分。
