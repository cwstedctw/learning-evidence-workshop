課後指南｜10/16 之後

昨天做過一次，回去自己再做一遍：三次版本，然後回頭看。

這一頁是給昨天來的老師的。先回想昨天做了什麼，再照七張卡在自己的電腦上重做：每張卡有「你說什麼、AI 會做什麼、你一定要自己看的」，每一句要貼給 AI 的話都有「複製」鈕，勾掉的卡這台電腦會記住。熟了以後用「一句話版」：只講目的，AI 自己把整件事做完。想先玩，下面有一個不用裝任何東西的模擬器。

壹昨天我們做了什麼

兩小時真正動手的是這四件。例子故意挑最小的：一個算 BMI 的小程式，三個版本。跟我們在人工智慧概論課上給學生的作業是同一套：在自己的電腦裡存三次版本，再回頭看前一版長什麼樣。工具叫 Git，但你不必記它的指令，指令交給 AI 助手（ChatGPT 桌面版的 Codex）代打，你只看它的計畫、看前後對照、然後點頭。

  1. 01把 AI 助手跟 GitHub 接起來Codex 開在你選的資料夾裡動手；GitHub 帳號登入過（gh），作者名字跟信箱從此寫進每一筆紀錄。這一步只是身分，還沒上傳任何東西。
  2. 02第 1 版：BMI 腳本用一句話請 AI 寫一支 bmi.py（輸入身高公分、體重公斤，算 BMI 和分級），跑一次看 170 公分、65 公斤約 22.5；把資料夾交給 Git 管理、存第 1 版。重點：AI 說做完了，你要親自打開資料夾看到那個檔、自己跑一次。
  3. 03第 2 版、第 3 版：改一次存一次同一個功能改成網頁版 index.html（雙擊就能算），存第 2 版；再加一個切換鈕做成中英雙語版，存第 3 版。每次都先看前後對照（只看 − 跟 ＋ 的行），版本說明是你自己的話。
  4. 04回頭看印出版本清單，把第 1 版的腳本拿出來看、跟第 3 版比差在哪。回頭看不是回到過去改，舊版永遠在；真要退回也是「再加一筆」，不刪歷史。這就是「我改過、什麼時候改、為什麼改」拿得出來的樣子。

全場只記一句話：挑一句不同意的、改掉、寫下為什麼。AI 只整理既有的分數與文字，不替老師打分數、不替老師下結論。

卡 1｜第 1 版：BMI 腳本，交給 Git

8 分

你做什麼

兩句分開貼，第一句做完、自己跑過一次，再貼第二句。

請在目前工作資料夾裡建一個資料夾 bmi，在裡面寫一支 Python 程式 bmi.py：執行後問身高（公分）和體重（公斤），印出 BMI（小數一位）和分級（過輕／正常／過重／肥胖，用台灣常見的 18.5、24、27 門檻）。寫好請你自己用 170 和 65 跑一次，把結果印給我看，並顯示 bmi.py 的完整路徑。不要安裝任何套件、不要上傳到任何地方。
請把 bmi 資料夾交給 Git 管理，存成第一個版本，版本說明寫「v1 BMI 腳本」。不要上傳到任何地方。如果需要先設定作者名字和信箱，名字用我的 GitHub 帳號名、信箱用 GitHub 註冊的信箱，設完告訴我你設了什麼。存完把版本清單印給我看。

AI 會做什麼

第一句：建資料夾、寫 bmi.py、自己跑一次給你看結果、印路徑。第二句：初始化 Git（第一次會設作者名字信箱）、存第 1 版（commit）、印版本清單。它問「要不要允許」→ 允許。

你一定要自己看的

①照它印的路徑打開資料夾，親眼看到 bmi.py。②自己跑一次（Windows 在資料夾空白處按右鍵「在終端機開啟」，打 python bmi.py）：170、65 → 約 22.5、分級「正常」。③版本清單一筆、說明是「v1 BMI 腳本」。④它設的名字信箱是你的。

卡 2｜第 2 版：同一個功能改成網頁版

6 分

你做什麼

貼這句。它改完先列前後對照，你看過再說「可以存」。

AI 會做什麼

新增 index.html（HTML＋一點 JavaScript，單檔、離線能開），列出新增了哪些行；等你說可以，存第 2 版、印清單。

卡 3｜第 3 版：中英雙語版

6 分

你做什麼

同一個 index.html 改，不另存；版本靠紀錄留、不靠檔名。

請把 bmi/index.html 改成中英雙語版：加一個語言切換鈕，可以換中文和 English，兩套文字都放在同一個檔裡，數字算法不變。先把前後對照列給我看，確認只改了 index.html；等我說「可以存」再存版本，版本說明寫「v3 中英雙語」，存完印版本清單。

AI 會做什麼

在同一個 index.html 加語言切換鈕與兩套文字，列前後對照；等你說可以，存第 3 版、印清單。

你一定要自己看的

①重新整理網頁，多一個切換鈕：按了變 English、再按回中文，數字算得一樣。②對照裡只有 index.html 的改動，bmi.py 沒被碰。③版本清單三筆：v1 腳本、v2 網頁版、v3 中英雙語，三句都是你的話。

卡 4｜回頭看：把第 1 版拿出來看、跟第 3 版比

5 分

你做什麼

這是昨天最後做的那件事。三句由淺到深，貼第一句就夠；第三句是真的要退回才用。

請把 bmi 資料夾裡「v1 BMI 腳本」那個版本的 bmi.py 完整內容印給我看，不要改現在的檔案、不要切換版本。然後列出第 1 版跟目前最新版（第 3 版）之間的前後對照：哪些檔新增、哪些檔改了。
請把 bmi 每一個版本「改了哪些檔、每個檔加減幾行」列成一張表，從第 1 版到最新版，附上每一版的時間與說明。不要改任何東西。
我決定撤銷第 3 版（中英雙語版），回到第 2 版的樣子。請不要刪掉任何歷史、不要用 reset 或強制：用 git revert 把第 3 版撤銷，當成新的一版存起來，版本說明照 git 預設的 Revert 寫法再加一句「因為【一句理由】」。存完印出版本清單，應該有四筆，第 3 版那筆還在。

AI 會做什麼

第一句：把第 1 版的 bmi.py 印出來（幕後是 git show）、列第 1 版到第 3 版的差異（git diff），現在的檔一個字都不動。第二句：列每版改了哪些檔、加減幾行。第三句：用「新的一版」撤銷第 3 版（幕後是 git revert），歷史四筆都在。

你一定要自己看的

①印出來的是第 1 版的腳本原樣。②差異裡 index.html 是新增的、bmi.py 沒動。③做了第三句的話：版本清單四筆、沒有任何一筆消失，重新整理網頁切換鈕不見了、回到第 2 版的樣子；AI 若提議「reset」「強制」「刪掉」，一律說不。回頭看不是回到過去改，是把舊版拿出來看；真要退回也是往前多存一版。

貳之二一句話版：只講目的，讓 AI 把整件事做完

上面七張卡是「一步一句、每步你看一次」，適合第一次。熟了以後其實不用拆步驟：你用白話講目的，AI 助手自己判斷要裝什麼、設什麼、跑什麼，做完回報。下面每一句都可以整句貼，【】換成你的。每句尾巴那段護欄請留著：它讓 AI 動手前先說計畫、要連網或動帳號先問你、不准刪歷史。

裝工具、登入（第一次用這台電腦）

我想在這台電腦用 Git 留課程資料的版本紀錄。請幫我檢查 git、GitHub CLI（gh）裝好了沒，沒有就幫我裝（Windows 另外確認 PowerShell 是 7 開頭，不是就一起裝）；裝好後幫我登入 GitHub（登入畫面跳出來我自己按）。每一步動手前先用一句話告訴我你要做什麼，做完列出你裝了什麼、設了什麼、哪些本來就有。

在這個資料夾用 Git（卡 1 的一句話版）

我想在目前這個資料夾用 Git 留紀錄。請把需要的都弄好：交給 Git 管理、作者名字用我的 GitHub 帳號名、信箱用 GitHub 註冊的信箱、把現在的內容存成第一版，版本說明寫「【這一版做了什麼，一句】」。不要上傳到任何地方。動手前先告訴我你的計畫，做完印出版本清單跟資料夾的完整路徑。

改了東西，存一版（卡 2、卡 3 的一句話版）

我改了【檔名】。請先把前後對照列給我看，等我說可以再存版本，版本說明寫：「【第 N 版：改了哪一格、為什麼，用你自己的話】」。只存這個資料夾裡的改動，不要動其他檔、不要上傳。

回頭看（卡 4 的一句話版）

幫我看看這個資料夾到目前為止改過哪些版本：每一版什麼時候、改了什麼、我當時寫的理由，用白話整理給我，再把最早那版跟最新版的差異列出來。不要改任何東西、不要切換版本。
我想退回【第 1 版】的寫法，但不要弄丟任何紀錄：不准 reset、不准強制覆蓋。把內容還原成那一版，當成新的一版存起來，說明寫「退回第 1 版，因為【理由】」，存完印出版本清單給我確認沒有少任何一筆。

接到 GitHub（卡 5 的一句話版）

我想把目前這個資料夾接到我的 GitHub，用不公開（Private）的 repo，名稱【資料夾名】；還沒有這個 repo 就幫我建，然後把所有版本紀錄上傳。做之前先告訴我：你會建什麼、上傳哪些檔、幾個版本，我看過再允許；要登入或授權的畫面我自己按。做完給我 repo 網址，並確認頁面上是鎖頭（不公開）。

把紀錄整理成計畫書用的表

請把這個資料夾的版本紀錄整理成一張表，欄位：日期、版本說明、改了哪個檔、加減幾行；存成 history.md 放在資料夾裡，然後存一版，說明寫「整理版本時間線」。這張表我要放進教學實踐研究計畫的「研究歷程」那一段，請用白話、不要有指令或代碼。

一句話版的三條護欄（每句尾巴已經寫進去了）：①動手前先說計畫，要連網、要動帳號、要裝東西先問你；②AI 說做完了，你要親自看到檔案或版本清單；③不准 reset、不准強制覆蓋、不准刪歷史。AI 提議這三件事，一律說不。
