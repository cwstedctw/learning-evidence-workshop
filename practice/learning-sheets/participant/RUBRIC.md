# 五區完成度 v1｜合成練習專用

**合成示範、不是學生作答**。版本1.0.0，機器規則見rubric.json。五區各20分，最多100分；是演練百分比，不是演講課正式評分政策，不含準時／遲交或學期換算，不做80–99常態對齊。

| 欄位 | 20分 | 0分 |
|---|---|---|
| pre_score | 課前問題有非空文字 | 留空 |
| reflection_score | 最有收穫有非空文字 | 留空 |
| facets_score | 六面向至少勾一項 | 全部未勾 |
| ai_score | 揭露「否」，或「是：用途」且用途非空 | 揭露留空 |
| message_score | 給講者的話有非空文字 | 留空 |

「學到很多」等空泛句仍是已完成；不按深度、立場、字數或態度加扣分。六面向可複選，但多勾不多給分。使用AI本身不扣分。

六面向只接受以下完整文字，以全形分號「；」分隔，不重複：AI 倫理與法律素養；權益尊重（智財／個資／隱私）；資安辨識與風險管理；資訊查核與 AI 內容判讀；社會影響與公平性；人類判斷與當責。空白表示未勾。

若代號、合成宣告、週次、欄位、面向或AI揭露格式不合法，工具會拒絕整批，不產生成果。AI看到不確定的內容應列待確認，教師先核對，不猜成0分。空白是可辨識的缺答，與非法格式不同。原始檔需修正時另存新檔、記理由再跑，不能改了證據卻當原檔。

AI輸出的五區分數加總為practice_total100；工具另列completed_sections（0–5）。教師final_score、decision、reason另存，不由工具填。若對規準有不同意見，記下修改草案，保留v1結果；本工具只支援v1，不會靜靜使用改過的規準。
