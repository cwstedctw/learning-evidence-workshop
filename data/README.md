# data/ — 示範用的合成學習證據（答案卡在這裡）

> **合成宣告**：這個資料夾裡的三份 CSV、`sample-analysis.json`，以及裡面所有代號、分數、反思短文，全部由 `make_demo_data.py` 用固定種子產生，**不代表任何真實學生**。每份 CSV 的第一行也寫著同一句宣告。工作坊全程只用這些資料，老師不需要帶任何真實的學生資料來。

這一頁是講師用的：欄位長什麼樣、數字怎麼生出來、**哪幾筆是故意埋的落差、哪一筆是預跑的 AI 分析故意分錯的**。老師在工作台按「講師模式」看到的答案卡，就是下面這份。

## 三份檔案

| 檔 | 領域 | 四個規準 | 證據從哪來 | 用途 |
|---|---|---|---|---|
| `project-presentation-scores.csv` | 課堂專題簡報（8 分鐘） | 內容正確、結構清楚、表達流暢、回應提問 | 口頭報告＋投影片（教師與同儕現場觀察紀錄） | **課堂主示範**（第三塊用這份） |
| `pe-squat-scores.csv` | 體育：深蹲動作品質（手機錄影 3 次） | 下蹲深度、膝蓋對齊、脊柱中立、控制與節奏 | 手機錄影的動作觀察紀錄（去識別化後只留評分與文字，不留影像） | 自選 |
| `lab-report-scores.csv` | 實驗報告（第 3 次實驗） | 假設與設計、數據處理、誤差討論、結論與反思 | 書面報告（文字、表格、圖） | 自選（化材／物理／環境通用） |
| `sample-analysis.json` | 三份都有 | — | — | 工作台「證據儀表板」預先跑好的分析：落差、AI 分類、答案卡 |
| `make_demo_data.py` | — | — | — | 生成程式；在這個資料夾裡跑 `python make_demo_data.py` 會覆寫上面四個檔 |

每份 24 筆，代號 `DEMO-S01` 到 `DEMO-S24`。

## 欄位（九欄，三份共用）

| 欄 | 內容 | 範圍 |
|---|---|---|
| `student_id` | 代號 | `DEMO-S01`…`DEMO-S24` |
| `task` | 評量任務 | 每份一個固定值 |
| `evidence_medium` | 證據從哪來 | 每份一個固定值 |
| `self_score` | 學生自評 | 4–16（四個規準各 1–4 級的加總） |
| `peer_score` | 同儕互評 | 4–16 |
| `teacher_score` | 教師評分 | 4–16 |
| `teacher_weakest_criterion` | 教師認為最弱的規準 | 四個規準之一 |
| `reflection_text` | 反思短文 | 來自程式裡的句子池，每句只用一次 |
| `synthetic_note` | 固定寫「合成資料」 | 提醒這一列是合成的 |

CSV 以 UTF-8（含 BOM）存檔，Excel 直接開不會亂碼；第一行是 `#` 開頭的合成宣告，第二行才是欄名——用程式讀的時候跳過第一行。

## 生成規則（看得懂就能自己改）

- **固定種子 `1016`**（取自 10/16），跑幾次結果都一樣。
- **非埋設的筆**：教師評分從 `[9,10,10,11,11,12,12,13,13,14,15]` 抽；自評＝教師分加 `[-1,0,0,1,1,2]` 之一（學生平均略高估自己）；互評＝教師分加 `[-1,-1,0,0,1,1]` 之一；最弱規準從四個規準隨機抽；反思類別從「具體指出弱點 ×3、歸因外部、同儕回饋有用 ×2、空泛、提到 AI」的權重抽，再從該類句子池抽一句。全部夾在 4–16。
- **埋設的筆**（每份 6 筆）：分數、最弱規準、反思類別、說明都寫死在程式的 `PLANTED` 表，就是下面的答案卡。
- **反思句子池**：六類（具體指出自己的弱點／把原因歸到外部／情緒或退縮訊號／同儕回饋有幫上忙／提到 AI 的使用方式／空泛、沒有具體內容），每個領域各自一池，每句只用一次；某類用完就改抽剩最多的那一類，所以同一份裡不會有兩筆反思一模一樣。
- **AI 分類＝真分類再故意改錯一筆**：`sample-analysis.json` 的 `ai_category` 是工作台顯示的「AI 分類」，`true_category` 是答案。兩者只差一筆（`ai_wrong_on`）：一則**具體指出自己弱點**的反思，被標成**空泛**——人一讀就知道不對，抽查才有靶。
- 資料列裡**不標**哪一筆是埋的；答案只在這份 README 與 `sample-analysis.json`。

### 課堂上怎麼用

1. **講師示範別把時間花在等 AI**：四塊都是老師自己跟著 AI agent 動手，講師只負責「先做一遍、大家跟著做」的節奏——但三塊的示範方式要不一樣。**第一塊一定現場真跑**（請 AI agent 建資料夾、交給 Git，就是要讓大家看見 AI 在做什麼、自己該看哪三件事）。**第二塊示範不等 AI**：工作台「Rubric 工作台」裡 P1 按「看範例輸出」→「把這張第 1 版填進左欄」、P2 按「看範例輸出」→「把示範的第 2 版填進右欄」，再按「比較兩版」，不用等 AI 就走完一輪；老師輪到自己做時才真的請 AI 起草。**第三塊示範直接開「證據儀表板」**：裡面就是預先跑好的那份分析，講師不必現場等 AI 回 P3／P4，省下的時間留給老師自己跑。
2. 第三塊老師自己請 AI 跑 P3／P4，再開工作台「證據儀表板」看預跑那份；**兩邊分類不一樣的地方就是要人看的地方**。
3. 「抽 3 筆回查」是隨機抽，24 筆抽 3 筆，抽到 ★ 那筆的機率大約八分之一；每位老師的抽查不一定會抽到。沒人抽到也沒關係——講師最後按「講師模式」點出來，重點不是抓到，是「要抽」。
4. 六筆埋設落差裡，**S14（互評極低、其他兩方一致）** 最值得講：它提醒老師去回查互評表，而不是去看學生——這是三方落差的核心解讀。
5. 自評虛高（S07／S05）跟自評偏低（S18／S23）放在一起看：同樣是「自評跟教師分差很多」，回饋要給的方向完全相反。

## `sample-analysis.json` 長什麼樣

三個頂層鍵：`project-presentation`、`pe-squat`、`lab-report`。每個底下：

| 鍵 | 內容 |
|---|---|
| `task`、`criteria`、`medium` | 跟 CSV 一致的任務、四規準、媒介 |
| `categories` | 六類反思的代碼對照（`skill`／`external`／`emotion`／`peer`／`ai`／`vague`） |
| `ai_category` | 工作台顯示的「AI 分類」，24 筆，**含一筆故意錯的** |
| `true_category` | 答案，24 筆；只在這份 README 與講師模式用 |
| `ai_wrong_on` | 故意分錯的代號 |
| `gaps` | 24 筆 `self_minus_teacher`、`peer_minus_teacher`、`flag`（埋設的 6 筆 `flag=true`） |
| `answer_key` | 埋設 6 筆的說明（上面答案卡的「說明」欄） |

守門腳本 `validate-workshop.mjs` 會核對：三份各 24 筆、第一行是合成宣告、欄位齊、`gaps` 的數字跟 CSV 算出來的一樣、`ai_category` 跟 `true_category` 只差 `ai_wrong_on` 那一筆。

## 換成自己的資料時

- 不要改這三份；工作台「證據儀表板」有「貼上自己的去識別化 CSV」，欄位照上面九欄（`task`、`evidence_medium`、`synthetic_note` 可以留空，`student_id` 用代號）。
- 貼之前先把姓名欄換成代號、刪掉信箱電話——平台匯出的檔先用提示詞 P5 請 AI 清成固定欄位，整理完先只看前 5 列確認格式。
- 自己的資料放私人 repo；`.gitignore` 已排除 `my-course/`、`real-data/`，把真實資料放那兩個資料夾名底下就不會被誤推上去。
